# Contributing

Contributions are welcome: new model adapters, recovered source links, corrected credits, event maps, tests and original voice packs.

Before adding a voice source:

1. identify the original/upstream project whenever possible;
2. add an acknowledgement in `catalog/voices.json`;
3. pin an integrity value (Git blob SHA, MD5/SHA256 plus size);
4. set `redistribution` honestly;
5. mark adult language with `adult: true`;
6. do not commit copyrighted audio without permission.

Before adding a model, read `docs/ADDING_MODEL.md`.
