# Vacuum Voice Hub v1.4.0 — Model Firmware Evidence Matrix

This software increment adds `vvh research firmware-matrix`, a strictly
offline model/firmware evidence reconciliation feature for up to 64 local
community reports per run. It validates exact catalog model identity and
per-report SHA-256, separates all five witnessed self-reported hardware
steps, and highlights conflicting firmware package digests and observations.

Reports contain no embedded paths, public evidence URLs, source binaries,
firmware content or credentials. No device actions are executed and no
new custom-install transports are enabled.

Hardware claims remain pending independent manual review, even when all
five observations are marked true. The historical research baseline of 223
models, 55 attributed voice variants and >=22 text-script locales is
preserved. Xiaomi X10 remains the sole VVH physically verified custom
voice installation target. Desktop signatures, manufacturer permissions,
legal audio rights and expanded firmware support are NOT implied.
