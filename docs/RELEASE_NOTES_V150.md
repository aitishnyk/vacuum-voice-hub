# v1.5.0 — Visual Audio Timeline and Local WAV Selection

This source/software update introduces a genuine offline waveform display
and local selected-range WAV export in the existing Creator Studio UI,
plus deterministic CLI waveform/cut-preview tools with safe new-file-only
writes. The selected audio can be A/B checked and human-reviewed, but
never overwrites a recording or authorizes any device transport.

Preserves all 223 research model identities, 55 credited voice variants,
at least 22 **text-only** locales, and Xiaomi X10 as VVH's sole physical
custom-voice hardware verification.

Source-only/public metadata ZIP is neither vendor licensed audio nor
signed installer. No universal hardware compatibility, independent
language fluency, LUFS/true-peak mastering, community device donations
or later roadmap milestones are claimed.
