# Vacuum Voice Hub 2.1.0 — product launch preparation

Give your robot vacuum a voice with a new dark home screen, working offline
speech demo, non-destructive preview and waveform, model-package export and a
safe handoff to Creator Studio. Eight original CC0 synthetic prompts are
bundled; external TTS is optional.

The original vector identity includes app icons and social artwork. The public
catalog is generated from canonical data and adds evidence filters, sorting,
model anchors and CSV export. All 223 model profiles, aliases, 55 voice variants,
22 text locales and existing installation limits are retained.

Start with [Getting started](GETTING_STARTED.md) and [Demo tutorial](DEMO_TUTORIAL.md).
Actual published assets appear only on
[GitHub Releases](https://github.com/aitishnyk/vacuum-voice-hub/releases).
Native builds, signing and platform acceptance have distinct statuses; consult
the machine-readable report before choosing a download. This preparation must
not be described as a signed, certified cross-platform stable desktop release.

Upgrade: back up Creator projects, install into a separate application directory,
and reopen the existing projects. No data migration or deletion is required.
v2.0.0's tag and assets remain immutable. Demo working copies live separately.

Known limits: demo packs are partial learning packs, local TTS needs licensed
engines/models, and only Xiaomi X10 has physical custom-voice installation
verification. Source tests do not verify robot playback. macOS notarization and
Windows signing require real owner credentials; unsigned builds stay unsigned.

Audio stays local. The public site does not host a remote Creator backend.
Review [Privacy and security](PRIVACY_SECURITY.md) and licensing notices before
sharing your own projects or distributing binaries.
